# Давай LLaMa

Личный помощник автора: разобраться в исходных материалах, подобрать фон под рассказ и подготовить редактируемый монтаж в CapCut. Моушен-графика развивается отдельным направлением; оболочки на ПК и в Telegram — после проверки монтажного пути.

**Состояние: основание и ограниченные технические опыты.** Есть локальная библиотека и проверка быстрого получения JPEG. Ближайшая реализация — один файл → до двух превью → краткая карточка → повторное использование результата. Автоматизация CapCut и монтаж ещё не реализованы.

## Принцип

Семь ролей поддерживают один путь автора. Каждый шаг заканчивается наблюдаемым результатом. Спорное решение возвращается к проверке основания; число сообщений не считается прогрессом.
