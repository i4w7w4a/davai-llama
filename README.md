# Давай LLaMa

Личный помощник автора: разобраться в исходных материалах, найти нужный момент и показать, чем подтверждён выбор. В дальнейшем — монтаж и удобные оболочки на ПК и в Telegram.

**Состояние: основание проекта. Готового видеоредактора пока нет.** Первый технический этап — один файл → метаданные и кадры с исходным временем → проверяемый пакет для анализа в Codex. Монтаж и Telegram придут после проверки этого пути.

Репозиторий публичный по прямому решению владельца. Рабочий язык — русский; идентификаторы кода и названия инструментов сохраняют исходное написание. Публичность репозитория не означает выбор open-source лицензии: лицензия продукта пока не назначена.

Медиа, транскрипции, личные пути, токены и результаты частного анализа остаются вне Git. Анализ подготовленных текстов и изображений в Codex требует передачи этих данных OpenAI; это не полностью офлайн-система.

## Принцип

Семь ролей поддерживают один путь автора. Каждый шаг заканчивается наблюдаемым результатом. Спорное решение возвращается к проверке основания; число сообщений не считается прогрессом.
