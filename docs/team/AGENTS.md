# Правила ролевых документов

Сохранять корневой `AGENTS.md` и авторский смысл 4i7. Не менять полномочия владельца или оркестратора через описание отдельной роли.

У роли должны быть: вход, область ответственности, предел полномочий, выход, проверка и условие остановки. Новая обязанность требует реальной проблемы; не размножать роли ради симметрии матрицы.

Документировать протокол взаимодействия, а не внутренние рассуждения. ID чатов и частные сведения хранить только в `.local/`. Для читателя GitHub достаточно имени роли и ссылки на задачу.
