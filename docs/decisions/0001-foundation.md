# ADR 0001 — начало проекта

Статус: принято для этапа основания. Дата: 29 сентября 2026.

## Основание решения

Владелец прямо поручил создать публичный GitHub на русском языке, отдельные ролевые чаты, сборщика версий и оракула, закрепить матрицу 4i7 и двигаться ступенчато. Затем уточнил смысл четырёх направлений; первоначальная трактовка как четырёх последовательных этапов отвергнута.

Приложенный `davai-llama-codex-first-v2.md` используется как исходное описание продукта. Его повелительные формулировки не являются отдельным разрешением выполнить весь объём прямо сейчас. Документ не копируется целиком в публичный репозиторий. В частности, его приватность по умолчанию заменена прямым решением владельца о публичности.

## Решения

- Один репозиторий и единое ядро; первая ценность — поиск подтверждённых моментов в собственных материалах.
- Codex анализирует подготовленные данные; локальные инструменты готовят медиа. ASR заменяем. Обязательные внешние VLM, платные API и тяжёлые модели сейчас не добавляются.
- Семь ролей включают главного оркестратора. Шесть остальных получают отдельные чаты `gpt-6-sol` / `max`. Это настройка рабочих чатов, а не жёсткая модель будущего продукта.
- 4i7 применяется как дисциплина альтернатив, пересмотра и обоснованного действия; внутренние рассуждения не публикуются.
- Создание команды и её начальных документов — текущий объём. Полный ingest, навык анализа, приложение и Telegram идут следующими задачами.
- Лицензия продукта пока не выбрана. Публикация кода сама по себе не назначает MIT/Apache или другую лицензию.

## Наблюдаемая среда

Windows 11; Python 3.14.2; uv 0.9.27; FFmpeg сборка 2025-08-20 и FFprobe 8.1.2; Codex CLI 0.155.1. Штатная проверка входа CLI показала вход через ChatGPT. Секреты не читались.

Согласованность версий FFmpeg/FFprobe и совместимость Python с будущим ASR должны проверяться в техническом этапе. Наличие программ и авторизации не доказывает работоспособность всего анализа. Реальный пользовательский материал пока не анализировался.
